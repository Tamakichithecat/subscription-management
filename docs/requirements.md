# 要件定義書

**プロジェクト名**: SubTrack Family（仮称）
**作成日**: 2026-03-23
**バージョン**: 1.0

---

## 1. プロジェクト概要

家族・グループで契約しているサブスクリプション（定期課金サービス）を一元管理するiOSアプリ。
費用の可視化・通知・相続を見越した契約情報の整理を目的とする。

---

## 2. ターゲットユーザー

- **主な利用者**: 家族（2〜6名程度）
- **ペルソナ例**:
  - 家計を管理したい親（家族の全サブスクを把握・整理したい）
  - 将来の相続・資産整理を見越して契約情報を残しておきたいシニア層
  - 家族内でサブスクを共有・分担して使っている世帯

---

## 4. 非機能要件

### 4.1 パフォーマンス
- アプリ起動〜ダッシュボード表示: 2秒以内（オンライン時）
- オフライン時はキャッシュされたデータを即時表示

### 4.2 セキュリティ・プライバシー
- 実際のクレジットカード番号や口座番号は保存しない（メモのみ）
- Supabase Row Level Security (RLS) でグループ外へのデータ漏洩を防止
- iOSのKeychain / Secure Enclave を利用した認証情報保護
- Face ID / Touch ID によるアプリロック

### 4.3 可用性・信頼性
- オフライン時はローカルキャッシュ（Core Data）で閲覧可能
- バックグラウンド同期: アプリ復帰時に差分同期

### 4.4 対応OS
- iOS 16.0 以上

### 4.5 対応デバイス
- iPhone（全サイズ）
- iPad（将来的に対応検討）

## 7. 制約・前提条件

- クレジットカード番号・銀行口座番号などの機密財務データは保存しない

- 為替レートはリアルタイムではなく日次キャッシュで十分
